# Prototype video

Final recording URL: https://drive.google.com/drive/folders/1rIy2lJdpMUVboZ0P00hCmf8vu-b3YTjB?usp=sharing

The generated `phase1_prototype_draft.mp4` is a reproducible visual prototype
walkthrough using actual RTL results. It is a rehearsal asset with on-screen
captions, all five confirmed names and enrollment numbers, and no recorded team
introductions. It is not
the final team presentation. Generate it with `make demo`.

Use [the five-speaker script](script.md) to record a presentation under five
minutes. Clearly introduce all five group members by name; the rubric does not
require five narrators. Upload the final
recording to a permitted host, enable access for evaluators, and test the link
while signed out. Keep large video files out of normal Git commits; link to the
hosted video here and in the README.
